# Visão Geral do Projeto - Mercado Portega

O **Mercado Portega** é um aplicativo Android desenvolvido para auxiliar na gestão de compras e organização de itens de mercado.

## Objetivo
O aplicativo deve perimitir que o usuário gerencie crie lista de compras, organize itens por categorias e permita que seja atualizado em uma lista o que já foi comprado.

## Tecnologias Utilizadas
- **Linguagem:** Kotlin
- **Arquitetura:** MVVM (Model-View-ViewModel)
- **UI:** Jetpack Navigation Component com Navigation Drawer
- **View Binding:** Para interação com os layouts XML
- **Lifecycle & ViewModel:** Para persistência de estado e lógica de UI

## Especificações do App
- Este aplicativo não terá chamadas para apis, todos os dados serão criados na sua respectiva camada.
