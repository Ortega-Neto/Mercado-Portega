# Funcionalidades e Módulos

O aplicativo é composto pelos seguintes módulos de interface:

## 1. Home
A tela principal do aplicativo. Atualmente serve como ponto de entrada e boas-vindas.

## 2. Shopping (Compras)
Gerenciamento da lista de compras. Utiliza o `ShoppingViewModel` para gerenciar o estado dos itens selecionados.
